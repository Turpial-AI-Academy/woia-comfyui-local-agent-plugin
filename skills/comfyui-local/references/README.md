# ComfyUI Local guide index

Read only the guides needed for the current operation. For a small prompt or widget change in a working project, keep its existing graph and inspect the affected inputs and outputs. A new modality, missing node, profile ambiguity, overwrite/delete request or failed execution needs the relevant deeper guide.

| Guide | Load trigger | Outcome |
|---|---|---|
| [Quick start](QUICKSTART.md) | Beginner guidance or a first task | One direct path from a request to media and Desktop |
| [Discovery](DISCOVERY.md) | First connection, changed server or uncertain capability | Actual local node/model/resource map |
| [Tool operations](TOOLS.md) | Any MCP operation | Correct server/tool choice and job ownership |
| [Creative direction](CREATIVE_DIRECTION.md) | Ideation, prompt writing, style, composition or shot design | A brief that translates into controllable inputs |
| [Images](IMAGES.md) | Image generation or editing | A compatible image graph and evaluated result |
| [Video](VIDEO.md) | Motion, animation, video editing or export | A shot plan, timed output and continuity checks |
| [Audio and 3D](AUDIO_3D.md) | Requested sound or spatial output | Modality-specific workflow and honest verification |
| [Workflows and Desktop](WORKFLOWS.md) | Graph construction, edits, imports or UI handoff | Preserved visual document and a valid executable graph |
| [Projects and production](PROJECTS.md) | Assets, revisions, variants, batches or run records | Traceable local project and artifact mappings |
| [Quality and troubleshooting](QUALITY_TROUBLESHOOTING.md) | Review, errors, resource pressure or optimization | Observed quality and a bounded repair |
| [Local setup orientation](LOCAL_SETUP.md) | Runtime unavailable or user asks about setup | Specific missing prerequisite without silent installation |
| [Primary sources](SOURCES.md) | Version-sensitive behavior or unfamiliar nodes | Source verification for the installed version |

The installed tool schemas and the connected ComfyUI source are authoritative for available operations. The upstream sites evolve; consult a page matching the installed version when behavior differs.
