# Optional deliverable templates

Copy and adapt a template into the user's project only when it helps the requested work. Empty fields are questions or pending work, never evidence.

- [Creative brief](creative-brief.template.md): when several creative decisions or reference assets need to stay consistent across variants.
- [Shot plan](shot-plan.template.md): when a video contains multiple shots, timing, camera instructions or coordinated sound.
- [Run review](run-review.template.md): when the user needs reproducibility, comparison or a durable quality review.
- [Guide routes](guide-routes.json): machine-readable routing to packaged guides, used to validate that advertised task families have a maintained route. It is not a workflow, installed-capability list or execution receipt.

No model names, hardware parameters, accounts, credentials or personal paths are required by these templates.
